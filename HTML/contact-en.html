FAQ

FREQUENTLY ASKED QUESTIONS

Is GameBack free?

Yes, GameBack is completely free. It is an open-source educational project with no commercial purpose.

Do I need to sign up?

In the current prototype version, no. Anyone can browse the catalogue and write reviews directly.

How do I install it?

You only need a web browser. Download the HTML file and open it. See the Installation Manual for full details.

Can I contribute?

Absolutely! Use the contact form to send us your collaboration proposal or improvement idea.
