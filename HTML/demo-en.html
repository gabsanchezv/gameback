Quick guide

HOW TO USE THE DEMO

📚
Browse the catalogue

Go to the "Catalogue" section and use the search bar or genre buttons to filter available games.

🎮
View a game profile

Click any game card to see its full profile with Metacritic score, platforms and reviews.

✍️
Write a review

From a game profile or the "Reviews" menu, click "Write Review", choose stars and write your opinion.

➕
Add a game

Click the "+ Add Game" button in the app header to add a new title to the catalogue with all its details.
